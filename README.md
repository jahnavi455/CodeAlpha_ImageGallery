# Responsive Image Gallery

## Overview

This project is a Responsive Image Gallery developed using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

The gallery allows users to view images in a clean and interactive layout with features such as image filtering, lightbox view, image navigation, hover effects, and responsive design.

---

## Features

* Responsive image gallery layout
* Image filtering using category buttons
* Lightbox image preview
* Next and Previous image navigation
* Image delete functionality
* Smooth hover animations
* Responsive design for mobile, tablet, and desktop screens
* Modern and user-friendly interface

---

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Explore the gallery features.

---

## Functionalities

### Image Categories

Users can filter images using category buttons such as:

* All
* Nature
* Cars

### Lightbox View

Clicking an image opens it in a larger preview window.

### Navigation

Users can:

* View next image
* View previous image
* Close the lightbox

### Delete Option

Images can be removed dynamically from the gallery.

### Responsive Design

The gallery automatically adapts to different screen sizes.
